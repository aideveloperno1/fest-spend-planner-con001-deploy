## 이 폴더는 무엇인가

제출 PDF와 사용법 문서(`docs/usage_guide.md`)에 넣는 **서비스 화면 사진**을 모아 둔 곳입니다.
모두 **시연용 합성 수치** 화면이며, 실제 분석 결과 화면은 여기 두지 않습니다.
화면이 바뀌면 명령 한 줄로 다시 찍을 수 있습니다(아래 "다시 찍기").

> 9/20 이후 1~5단계에 사업 유형, 지역 소비 프로필, 새 질문, 공개 변경 순번과 프로필 별첨이 추가됐습니다. 현재 세션에는 연결 가능한 브라우저가 없어 이미지를 갱신하지 못했습니다. 문서 본문은 현재 코드 기준이며, 이미지는 재촬영 전 참고용입니다.

## 자세한 설명 (개발자용)

### 캡처 환경 (사용자 결정 2026-09-17)

공개 배포가 보류되어 **로컬 실행 + 합성 자료**로 찍는다. 사용자 Chrome과 분리된 창 없는 Chrome으로 찍어 주소창·북마크가 들어가지 않는다.

### 다시 찍기

```powershell
uv run python scripts/capture_screenshots.py          # 3단계 AI 참고 의견 포함 (GEMINI_API_KEY 필요)
uv run python scripts/capture_screenshots.py --no-ai  # AI 영역 없이
```

- 스크립트는 셸의 `PSM_` 설정을 비우고 합성 근거로 서버를 따로 띄우며, 상단 표시가 "시연용 합성 수치"가 아니면 멈춘다
- AI 문장은 찍을 때마다 달라지므로 찍은 뒤 확인한다
- `05_saved_markdown.png`는 스크립트로 만들지 않는다

### 이름 규칙

번호는 단계, 뒤는 화면 상태를 뜻한다. 같은 화면을 다시 찍으면 덮어쓴다.

### 원칙

- **합성 수치 화면만** 둔다. 상단의 "시연용 합성 수치" 표시가 보이게 찍는다
- 실제 분석 결과 화면 캡처는 공개 저장소에 올리지 않는다 (팀 비공개 공간 또는 `private/`)
- 브라우저 주소창·개인 북마크·다른 탭이 보이지 않게 찍는다
- 가로 1440px 기준, PNG. 01·02_national·03·05는 전체 페이지, 02_hold는 1440×900, 04는 1440×1300 화면 한 장
- 04의 입력 예시: 수집 자료 "쿠폰 사용 실적, 참여 점포 정산 자료", 확보 여부 "협의 중", 담당 "관광정책과", 주기 "월 1회" (사용자 확인 9/17)
