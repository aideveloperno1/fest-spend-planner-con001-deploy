# 공개 배포 데이터

이 폴더에는 데이터 담당이 공개 개발자 전달본과 함께 제공한 설명·검증 문서만 둔다.

서비스가 직접 읽는 공개 합성 JSON은 다음 위치에 있다.

```text
src/policy_signal_map/resources/evidence/review_evidence_public_v2.1.json
```

공개 JSON은 실제 지역 분석 결과가 아니라 12개 가상 지역 시나리오와 전국 합성 자료다. 서비스의 **공개 시연 지역**에서 A~L 시나리오를 고를 수 있다.

이 저장소에는 다음 자료를 넣지 않는다.

- 비공개 실데이터 JSON
- 실제 지역 대응표
- 원본·중간 CSV, Excel, Parquet, pickle 파일
- 비밀키가 든 `.env`

포함 문서:

- `README_근거파일_2.1.md`: 공개 전달 형식 설명
- `검증_절차_가이드.md`: 전달본 검증 순서
- `검증결과_요약_공개용.md`: 공개 가능한 검증 결과 요약
- `임계값_결정표_v2.1.md`: 공개 운영 기준 설명
