# `src/` — 소스 코드를 담는 바깥 폴더

## 이 폴더는 무엇인가

서비스 코드를 담는 바깥 상자입니다. 파이썬 프로젝트 도구(uv)가 권하는 방식대로, 실제 코드는 안쪽 `policy_signal_map/` 폴더 하나에만 둡니다.

## 파일 목록

| 파일 | 하는 일 (쉬운 말) | 언제 보거나 고치나 |

## 자세한 설명 (개발자용)

- uv 프로젝트의 src 레이아웃 폴더다. 서비스 패키지 `policy_signal_map/` 하나만 둔다
- 여기에 다른 파일이나 패키지를 추가하지 않는다
- 패키지 구조와 의존 방향은 [policy_signal_map/README.md](./policy_signal_map/README.md)를 본다
- `tests/`와 `scripts/`는 src 밖(저장소 루트)에 둔다
