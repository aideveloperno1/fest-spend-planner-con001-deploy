# `resources/evidence/` — 시연용 가짜(합성) 근거 파일

> 최신화: 2026-09-22

## 이 폴더는 무엇인가

서비스가 읽는 **공개 시연용 합성 근거 파일**을 두는 곳입니다. 이 배포 프로젝트에는 내부용 데이터를
두지 않습니다. 설정을 따로 하지 않으면 계층 합산 공개 합성 파일을 읽습니다.

## 파일 목록

## 자세한 설명 (개발자용)

### `review_evidence_demo_v1.json` 내용

- `schema_version`: `"2.0"`, `dataset_version`: `"demo-001"`. 기존 화면 회귀 테스트용 파일
- 레코드 `DEMO-R07-NATIONAL` — 전국, 2026-01~06, 6개월 모두 `ok`
  - 인접 5구간: 비교 A **반대 2개**(01→02, 02→03), **같음 3개** — 반대 방향만 모은 자료가 아님
  - 04→05는 비중 변화 +0.0022%p (0.01%p 미만 표시 규칙 확인용)
  - 기간 합산 비중 8.3778% (월 비중 평균 8.3760%과 다름)
  - applicability: R07 `allowed` / R06 `blocked` / R02 `needs_review`
### 시도 레코드 16건 — 지역마다 다른 상황

입력 화면의 시도 **17곳 중 16곳**에 레코드를 둔다. **세종특별자치시는 일부러 비워** "선택한 지역의
자료가 없어 전국으로 되돌립니다" 화면을 시연할 수 있게 했다. 시군구를 고르면 그 시도 레코드를 쓴다.

어느 지역에 어느 상황을 둘지는 **시연 편의**로 정한 것이다. 그래서 사유 문장은 지역이 아니라
**자료의 상태**만 말한다 ("○○ 지역이 문제"로 읽히지 않게).

| 지역 (`region_key`) | evidence_id | 담은 상황 | 화면 |
|---|---|---|---|
| 서울 `1100000000` | `…-SEOUL` | 정상, 반대 구간 2개 | 차트·표·요약 |
| 부산 `2600000000` | `…-BUSAN` | 정상, 반대 구간 0개 | "반대 방향으로 움직이지 않았습니다" |
| 대구 `2700000000` | `…-DAEGU` | 3월 `invalid_input` | "입력 확인 필요" + 사유 |
| 인천 `2800000000` | `…-INCHEON` | 3월 `no_data` | "자료 없음", 앞뒤 구간 보류 |
| 광주 `2900000000` | `…-GWANGJU` | 4월 `invalid_denominator` | "분모 0 · 계산 불가" |
| 대전 `3000000000` | `…-DAEJEON` | 1월 외국인 금액 0 | 증감률 "계산 불가", 금액 차이는 유효 |
| 울산 `3100000000` | `…-ULSAN` | 1·2월 값이 완전히 같음 | "변화 없음" |
| **세종 `3600000000`** | **(없음)** | **자료 없음** | 전국으로 되돌리고 이유 표시 |
| 경기 `4100000000` | `…-GYEONGGI` | 비중 변화 0.01%p 미만 | "0.01%p 미만 (감소)" |
| 강원 `5100000000` | `…-GANGWON` | 정상, 반대 구간 2개 | **예시 기획(강릉시)이 쓰는 레코드 — 캡처가 이 화면** |
| 충북 `4300000000` | `…-CHUNGBUK` | 전체 분모와 미상 제외의 방향이 다름 | 비교 B만 "방향 다름" |
| 충남 `4400000000` | `…-CHUNGNAM` | 2월 미상 금액 = 전체 금액 | 미상 제외 비중 "계산 불가" |
| 전북 `5200000000` | `…-JEONBUK` | R07 `needs_review` | 수치는 보이고 **요약만 보류** |
| 전남 `4600000000` | `…-JEONNAM` | R07 `blocked` | 지역 수치를 쓰지 않고 **전국으로 되돌림 + 사유** |
| 경북 `4700000000` | `…-GYEONGBUK` | 6개월 중 계산 가능 3개월 | **표본 부족** — 차트·요약 접고 계산하지 못한 달만 |
| 경남 `4800000000` | `…-GYEONGNAM` | 정상 (평범) | 차트·표·요약 |
| 제주 `5000000000` | `…-JEJU` | 정상 (평범) | 차트·표·요약 |

- 모든 시도 레코드: `region_basis: "merchant_location"`, R06·R02는 `blocked`
- `region_key`는 **행정표준코드 10자리**(연결 키 C-1). **화면에는 지역 이름으로 나온다**
- `evidence_id`에는 읽을 수 있는 이름을 쓴다 — 근거 칩에 그대로 보이기 때문이다
- 담을 수 **없는** 것: **억원 단위 화면**. 합성 파일은 수만 원 이하 가상 규모만 쓰기로 해서(`test_demo_uses_synthetic_scale_only`) 억원은 `tests/fixtures/evidence/large_amounts.json`에서만 확인한다

### 시군구 레코드 266건 — 태백시를 제외한 입력 화면의 시군구를 덮는다

입력 화면의 시군구 **267곳 중 266곳**에 레코드를 둔다. 태백시는 의도적으로 시도 자료로 넓히며, 화성시 출장소 2곳은 지역 선택과 파일에서 제외했다.
수치는 `scripts/build_demo_evidence.py`의 `_numbers()`가 **행정표준코드에서 만들어 낸 가상 값**이다
(난수를 쓰지 않아 같은 코드면 항상 같은 값). 전체 금액은 1만 원을 넘지 않는다.

네 곳은 손으로 설계했고, 한 곳은 **일부러 비워** 사다리(시군구 → 시도 → 전국)를 화면으로 보인다.

| 시군구 | evidence_id | 상황 | 고르면 화면이 |
|---|---|---|---|
| 강원 **강릉시** | `…-강원-강릉시` | 정상 6개월, 반대 2구간·같음 3구간 | **예시 기획이 쓰는 화면 — 캡처가 이것** |
| 강원 춘천시 | `…-강원-춘천시` | 정상 6개월 | 춘천시 자료를 그대로 사용 |
| 서울 종로구 | `…-서울-종로구` | 계산 가능 3개월 | **표본 부족 → 서울특별시 자료**로 넓히고 이유 표시 |
| 제주 제주시 | `…-제주-제주시` | R07 `blocked` | **사용 불가 → 제주특별자치도 자료**로 넓히고 사유 표시 |
| 강원 **태백시** | **(없음)** | 일부러 비움 | **자료 없음 → 강원 자료**로 넓히고 이유 표시 |

- `evidence_id`는 **근거 칩으로 화면에 그대로 보이므로** 행정표준코드를 쓰지 않는다. `DEMO-R07-SIGUNGU-강원-강릉시`처럼 이름을 쓴다
- "중구"처럼 여러 시도에 같은 이름이 있어 **시도 이름을 앞에 붙여** 구분한다
- 실제 자료에서는 시군구 표본이 작아 전면 적용이 어렵다. **시연 자료라서** 전부 채울 수 있는 것이다

- 레코드 `DEMO-R07-SIDO-HOLD` — 가상 시도 `DEMO-SIDO-A`
  - 03월 `no_data`, 05월 `invalid_denominator` → 비교 가능 1개, 보류 4개
  - applicability: R07 `needs_review` / R06·R02 `blocked`
  - 2단계 "자료가 부족한 경우 보기" 화면용. **예시는 한 건만 보여 준다**(레코드가 늘어도 화면이 길어지지 않게)

- 월별 수치 표: [1근거계산계층계획.md 9장](../../../../1근거계산계층계획.md#9-1-5-합성-근거-파일)
- `tests/test_demo_evidence.py`가 생성 스크립트와의 일치, 구간 구성, 가상 규모를 검사한다

### 원칙

- **실제 카드 분석 수치를 쓰지 않는다.** 최종기획서 4-2장 표의 금액·비중을 그대로 또는 비슷하게 옮기지 않는다. 가상 규모(외국인 800, 전체 10,000 단위 등)를 쓴다
- 모든 레코드 `data_kind: "synthetic"`, `dataset_version`은 `demo-`로 시작
- 손으로 비중을 적지 않는다. 스크립트가 정수 금액에서 계산한다
- 테스트 전용 경계 사례는 여기가 아니라 `tests/fixtures/evidence/`에 둔다
- 이 배포 프로젝트에는 내부용 또는 실제 분석 파일을 추가하지 않는다
