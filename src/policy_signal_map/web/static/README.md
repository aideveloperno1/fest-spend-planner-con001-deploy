# `web/static/` — 화면 모양(CSS)과 즉시 반응(JS)

> 최신화: 2026-09-19

## 이 폴더는 무엇인가

브라우저가 그대로 내려받아 쓰는 파일을 두는 곳입니다. **화면 모양(색·배치·인쇄 모양)**과, 페이지를 다시 불러오지 않고 **바로 반응하는 기능**(차트 전환, 입력 칸 펼치기, 저장 창 열기 등)이 여기 있습니다.
확인·계산·저장할 내용 결정은 서버가 하고, 여기는 편의 기능만 맡습니다. 누구나 내려받을 수 있으므로 실제 자료나 비밀 키를 두지 않습니다.

## 파일 목록

| 파일 | 하는 일 (쉬운 말) | 언제 보거나 고치나 |
|---|---|---|
| `css/` | 화면 **모양** (스타일 파일 하나) | [README](css/README.md) |
| `js/` | 화면 **즉시 반응** 스크립트 (기능마다 파일 하나) | [README](js/README.md) |

## 자세한 설명 (개발자용)

### 역할 요약

`/static` 경로로 제공되는 파일. 화면 모양(CSS)과 서버 렌더링만으로 어려운 즉시 반응(JS)을 담당한다.
JS는 편의 기능만 맡고, **검증·계산·저장 내용 결정은 서버가 한다.** JS가 꺼져도 입력·제출·문서 보기는 동작해야 한다 (저장 위치 선택 창 제외).

이 폴더의 파일은 누구나 내려받을 수 있다. 실제 자료·API 키를 두지 않는다.

### 외부 자원

| 자원 | 불러오는 곳 | 비고 |
|---|---|---|
| Pretendard 1.3.9 | `templates/base.html` (jsDelivr CDN) | SIL OFL |
| Chart.js 4.5.1 | `templates/steps/evidence.html` (jsDelivr CDN, 버전 고정) | MIT, 2단계에서만 로드 |

CDN을 쓸 수 없는 환경(내부 시연 오프라인 등)이 확인되면 `static/vendor/`에 파일을 내려받아 두는 방식으로 바꾼다.
