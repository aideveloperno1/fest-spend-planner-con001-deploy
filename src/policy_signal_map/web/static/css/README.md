# `web/static/css/` — 화면 모양

> 최신화: 2026-09-19

## 이 폴더는 무엇인가

서비스 화면의 **색, 글자, 배치, 카드·버튼 모양, 인쇄(PDF 저장) 모양**을 정하는 스타일 파일을 두는 곳입니다.
파일은 하나이고, 안에서 화면 단계별로 구역을 나눠 두었습니다.

## 파일 목록

| 파일 | 하는 일 (쉬운 말) | 언제 보거나 고치나 |
|---|---|---|
| `landing.css` | **랜딩 화면(`/`) 전용 스타일.** 구역 배치, 지역 사다리, 등장·방향 비교 같은 움직임, 동작 줄이기·인쇄 대응 | 랜딩 모양이나 움직임을 바꿀 때 |
| `style.css` | **전체 화면 스타일.** 색상 기준값, 상단·단계 표시줄, 입력 칸, 단계별 화면, 인쇄 모양, AI 참고 의견 영역 | 색·간격·배치를 바꾸거나 새 화면 요소의 모양을 정할 때 |

---

## 자세한 설명 (개발자용)

### 파일 크기

**`style.css` 한 파일로 유지한다 (사용자 결정 9/17, `checks.md` 1장).** 처음 세운 "700줄을 넘으면 나눈다" 기준은 폐기했다. 나눠도 화면 동작·속도는 같고, CSS는 뒤에 적은 규칙이 앞 규칙을 덮으므로 나누는 과정에서 순서가 바뀌면 인쇄 모양 등이 달라질 위험이 있기 때문이다. 찾을 때는 아래 주석 구역 제목으로 검색한다. 팀원과 함께 CSS를 자주 고치게 되면 그때 다시 본다.

### `style.css` 구성 (주석 구역 순서)

1. **디자인 토큰** (`:root`) — 시안 색상: 배경 #F1F4F9, 카드 #FFFFFF, 본문 #1B2430, 강조 #2563EB, 추가 확정 필요 #A8761A / #FDF4DE, 오류 #C2410C(입력 오류에만)
2. **상단** — 상단바·단계 표시줄
3. **레이아웃** — 본문+오른쪽 패널 2열, 900px 이하 1열, 카드
4. **버튼**
5. **입력** — 칩, 세그먼트, 강조 박스, 오류
6. **오른쪽 패널** — 요약, 규칙 목록
7. **근거 화면 (2단계)** — 범위 칩, 안내·보류 상자, 요약 문장, 차트 카드·대체 문구, 표(가로 스크롤, 보류 행 회색, 방향 다름 굵게), 계산 방법·해석 한계 카드(자료의 한계·서비스 해석 원칙 두 묶음 소제목 `.notes-heading`), 보류 사례 접힘 영역, 오류 목록. `.stack`은 `minmax(0, 1fr)`로 표 최소 폭이 본문을 밀어내지 않게 함 (9/16 400px 폭에서 본문 766px로 넓어지는 문제를 발견해 수정)
8. **검토 질문 (3단계)** — kind별 규칙 카드 (질문: 파란 테두리 / 안내: 회색 / 추가 확정 필요: 노랑 / 보류: 회색 점선), 근거 칩, "왜 묻나요?" 박스
9. **보완 선택 (4단계)** — 대안 카드 선택 상태, 실행 조건 입력 박스(파란 점선), 재확인 필요 목록
10. **보완 기획안** — 문장 줄(변경·추가는 파란 배경과 칩), 근거 추적 패널, 문서 보기(`pre`), 변경 전후 표
11. **인쇄·PDF 저장** — `@media print`: A4 14mm/12mm 여백, 상단바·단계 표시줄·버튼 숨김, 카드 그림자 제거와 `break-inside: avoid`, 표 최소 폭 해제(인쇄 가능 폭 186mm에서 잘리지 않음), 하단 고지는 남김. 배경색이 꺼져도 구분되게 변경 줄은 **왼쪽 선**으로 표시
12. **AI 참고 의견** — 점선 카드(`.ai-card`), 의견 줄(`.ai-opinion`), 모델 선택 칸(`.ai-model-form`, `.ai-model-row`). 인쇄 구역보다 뒤에 있으므로 인쇄용 규칙을 추가할 때 이 구역도 확인한다

**규칙 관리 번호(R07 등)는 화면에 쓰지 않는다** (사용자 결정 2026-09-18). 번호를 표시하는 클래스를 새로 만들지 않는다.

### 원칙

- 방향 차이를 빨간색으로 표시하는 클래스를 만들지 않는다 (워크플로우 8-3)
- 한글 라벨에 고정폭 글꼴(monospace)을 쓰지 않는다 (글자 간격 깨짐 확인됨). 숫자 열에만 `font-variant-numeric: tabular-nums`
- 모바일 폭(400px)에서 가로 스크롤은 표·문서 영역 안에서만 생기게 한다
