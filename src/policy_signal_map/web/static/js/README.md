# `web/static/js/` — 화면이 바로 반응하게 하는 스크립트

> 최신화: 2026-09-19

## 이 폴더는 무엇인가

브라우저에서 돌아가는 작은 자바스크립트 파일들입니다. 버튼을 누르거나 선택을 바꿀 때 **페이지를 새로 불러오지 않고 화면을 바로 바꾸는 일**(칸 보이기·숨기기, 차트 그리기, 파일 저장 등)을 맡습니다.
입력이 올바른지 확인하거나 숫자를 계산하는 일은 하지 않습니다. 그런 일은 모두 서버가 하고, 이 파일들은 서버가 준 값을 보여 주기만 합니다.

## 파일 목록

| 파일 | 쓰는 화면 | 하는 일 (쉬운 말) | 언제 보거나 고치나 |
|---|---|---|---|
| `landing.js` | 랜딩 (`/`) | 스크롤에 맞춘 **등장 효과**(화면에 들어올 때마다 재생 — 위로 올렸다 내리면 또 보인다)와 **지역 사다리 칩** 전환. 전부 향상일 뿐이라 이 파일이 없어도 모든 글자가 보인다. `?motion=off`면 움직임 없이 최종 상태 | 랜딩 움직임을 바꿀 때 |
| `input.js` | 1 기획 입력 | "기타"를 고르면 설명 칸을 보여 주고, 지역 범위에 맞게 시도·시군구 목록을 바꾸는 등 **입력 칸을 상황에 맞게 바꿈**. 오른쪽 **입력 상태** 칸(필수 항목·추가 확정 필요 목록)을 **입력하는 즉시 다시 셈**. 빠뜨린 칸이 있으면 그 칸으로 화면을 옮김 | 1단계 입력 칸 동작이나 입력 상태 표시를 바꿀 때 |
| `charts.js` | 2 근거 확인 | 월별 외국인 결제금액 막대 차트와 비중 선 차트를 **그림**. [전체 분모]/[미상 제외] 버튼으로 비중 차트를 바꿈. 차트 도구를 못 불러오면 "표를 보라"는 안내만 보여 줌 | 차트 모양·색·버튼을 바꿀 때 |
| `opinions.js` | 3 검토 질문 (AI 참고 의견을 켠 경우만) | 화면이 뜬 뒤 **AI 참고 의견을 따로 받아 와** 채움. 기다리는 동안·실패했을 때 안내 문구를 보여 줌 | AI 의견 칸의 표시 방식을 바꿀 때 |
| `choices.js` | 4 보완 선택 | "채택·수정"과 대안을 고르면 **그에 맞는 입력 칸**(실행 조건, 수정 문장)만 보여 줌. 저장에 실패하면 **오류 자리로 화면을 옮김** | 4단계 입력 칸 보이기 규칙을 바꿀 때 |
| `save.js` | 5 보완 기획안, 전체 문서, 요청서 초안 | [결과 저장]을 누르면 **저장 위치를 고르는 창**을 띄워 Markdown 파일로 저장. 화면을 연 뒤 기획 또는 근거 자료가 바뀌었으면 저장하지 않고 4단계 재확인을 안내 | 저장 방식이나 안내 문구를 바꿀 때 |
| `print.js` | 5 보완 기획안, 전체 문서, 요청서 초안 | [PDF로 저장]을 누르면 **브라우저 인쇄 창**을 엶(대상을 "PDF로 저장"으로 고르면 PDF가 됨) | 거의 고칠 일 없음. 인쇄 모양은 `css/style.css`에서 바꿈 |
| `trace.js` | 5 보완 기획안 | 문장 옆 근거 칩을 누르면 아래 **근거 추적 목록에서 해당 근거를 강조**함 | 근거 추적 강조 방식을 바꿀 때 |

## 자세한 설명 (개발자용)

### 원칙

- 빌드 도구 없이 브라우저가 바로 읽는 일반 JS (모듈 번들 없음)
- 파일마다 즉시 실행 함수로 감싸 전역 변수를 만들지 않는다
- 서버가 `<script type="application/json">`으로 넘긴 데이터만 사용하고, 숫자를 다시 계산하지 않는다
- 사용자 입력·AI 출력을 `innerHTML`에 넣지 않는다 (`textContent`, `new Option()` 사용)
- 필수 검증은 서버가 한다. JS는 표시만

### `input.js`

- 기타 선택 시 설명 칸 표시(`data-toggle-other`, `data-other`)
- 지역 범위(전국·시도·시군구)에 따라 시도·시군구 선택 표시, 시도를 바꾸면 시군구 목록을 `regions-data`에서 다시 채움(시군구가 없는 시도는 선택 잠금)
- 예산: 입력 금액을 `1,000원`처럼 표시(`data-note="budget"`). **금액 칸을 잠그지 않는다** — 잠그면 입력한 금액이 서버로 가지 않고 사라진다(9/18). [미정]과 금액이 함께 있으면 "하나만 남겨 주세요" 안내
- 지표 용도를 고르면 안내 문구 표시(`data-note="indicator_use"`)
- **입력 상태 패널을 입력 즉시 다시 셈**(`data-summary="required|pending-count|pending-list"`). 항목 이름과 판단 기준은 `plan/validation.py`와 같게 유지한다(다르면 제출 후 숫자가 달라 보인다). 저장은 [검토 시작]을 눌러야 된다
- 서버가 오류로 돌려보낸 경우 첫 `.has-error`로 스크롤

### `charts.js`

- 입력: `<script id="chart-data" type="application/json">` (`web/evidence_view.chart_data`)
  ```
  { "unit": "원" | "억원",
    "labels": ["1월", ...],
    "status": ["ok", "no_data", ...],
    "foreign_amount": [820, null, ...],       원 단위면 정수, 억원이면 소수 둘째 자리, 계산할 수 없는 월은 null
    "share_all_pct": [8.2, ...], "share_known_pct": [8.5864, ...] }
  ```
  (위 숫자는 형식 설명용 예시다)
- Chart.js 4.5.1은 jsDelivr CDN에서 `integrity`(sha384)와 함께 불러온다. `window.Chart`가 없으면 차트 카드를 숨기고 `.chart-fallback`을 보인다 (9/16 주소를 임시로 틀리게 바꿔 확인)
- 금액 막대 차트, 비중 선 차트 (`button[data-denominator]`로 전체 분모 / 미상 제외 데이터셋 전환)
- null은 막대·점을 그리지 않고 끊는다 (`spanGaps: false`). 0으로 그리지 않는다. 툴팁은 null이면 "계산 불가"
- 비중 축 눈금·툴팁은 소수 둘째 자리
- 색상: 시안 파랑 계열만. 반대 방향 구간을 빨간색으로 강조하지 않는다

### `opinions.js`

- 3단계 화면이 뜬 뒤 `/step/3/opinions`(JSON)를 요청해 `[data-ai-list]`에 의견을 채운다
- `state`가 `off`면 AI 영역을 숨기고, `failed`면 "AI 의견을 불러오지 못했습니다", 의견이 모두 걸러졌으면 "이번에는 참고 의견이 없습니다"
- 출처 표시는 모델 표시 이름(`model_label`)과 생성 시각
- AI 영역은 처음부터 보인다(의견을 기다리는 동안에도 모델 선택 칸을 쓸 수 있게). 기다리는 동안 "모델을 바꾼 직후나 PC를 켠 뒤 처음에는 1~2분 걸릴 수 있다"는 안내가 템플릿에 있다

### `choices.js`

- 질문 폼(`.choice-form`)마다 고른 결정(`decision`)과 대안(`option_id`)을 보고 표시를 바꾼다
- 채택·수정이면 대안 카드 선택 표시(`option-card-on`), 원안 유지·보류면 대안 카드 흐리게(`option-card-off`)
- [수정]일 때만 `modified_text` 입력칸 표시
- 고른 대안에 실행 조건이 있을 때만(`data-has-execution="1"`, R07·R03·R04의 대안 A) `.execution-box` 표시

### `save.js`

checks.md 결정: [결과 저장] → 저장 위치 선택 창 → 사용자가 고른 폴더에 Markdown 저장.

1. 버튼의 `data-url`(`/step/5/download`, 요청서는 `?kind=request`)과 `data-filename`을 읽는다
2. **본문을 먼저 `fetch`한다** (6-5d). 409(기획 또는 근거 자료 변경으로 재확인 필요)면 4단계에서 다시 확인하라는 안내만 하고 저장하지 않는다. 그 밖의 실패도 안내만 한다
3. `window.showSaveFilePicker`가 있으면 위치를 고르게 하고(취소하면 "저장을 취소했습니다") `createWritable()` → `write()` → `close()`
4. 없으면 (Firefox·Safari 등) 받은 본문을 Blob으로 내려받고 "저장 위치 선택을 지원하지 않는 브라우저라 내려받기 폴더에 저장했습니다" 안내. 고른 위치에 쓰지 못하면 같은 방식으로 내려받는다. 안내 문구는 화면의 `[data-save-note]` 자리에 넣는다
- 저장 위치 선택 창은 HTTPS 또는 localhost에서만 동작한다. 공개 배포는 HTTPS 필수
- 서버에는 파일을 남기지 않는다 (최종기획서 4-5)

### `print.js`

- 서버에서 PDF를 만들지 않는다. 서버 PDF 생성기(WeasyPrint·headless Chrome)는 한글 글꼴과 브라우저 바이너리를 배포에 얹어야 해서 공모전 일정에 위험이 크다
- `.md` 저장과 용도가 다르다: `.md`는 담당자가 **고쳐 쓰는 원고**, PDF는 **그대로 공유하는 사본**
- 인쇄 모양은 `style.css`의 `@media print`가 정한다

### `trace.js`

- `data-trace-link` 칩을 누르면 `data-trace`가 같은 근거 항목에 `trace-on`을 준다 (앵커 이동은 HTML만으로 동작)
- 패널 내용은 서버가 렌더링해 둔 것을 보여주기만 한다
