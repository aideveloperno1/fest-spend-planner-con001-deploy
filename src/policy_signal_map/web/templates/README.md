# `web/templates/` — 화면의 HTML 틀

> 최신화: 2026-09-17

## 이 폴더는 무엇인가

화면에 보이는 **HTML 틀(템플릿)**을 두는 곳입니다. 서버가 계산한 값을 이 틀의 빈자리에 채워 브라우저로 보냅니다.
틀은 **값을 보여 주기만** 하고 계산이나 판단은 하지 않습니다. 모든 화면이 함께 쓰는 바깥 틀은 여기에, 단계별 화면과 반복되는 조각은 하위 폴더에 있습니다.

## 파일 목록

| 파일 | 하는 일 (쉬운 말) | 언제 보거나 고치나 |
|---|---|---|
| `base.html` | **모든 화면의 공통 바깥 틀**: 위쪽 서비스 이름·자료 종류 표시·[처음으로], 1~5단계 표시줄, 아래쪽 고지 문구 | 모든 화면에 공통인 부분을 바꿀 때 |
| `error.html` | **근거 파일을 읽지 못했을 때** 보이는 안내 화면 (오류 목록과 다음에 할 일) | 오류 안내 문구를 바꿀 때 |
| `steps/` | **단계별 화면 틀** (1~5단계, 요청서 초안) | [README](steps/README.md) |
| `partials/` | 여러 화면에서 **반복되는 조각** (근거 표시 칩, 월별 표, 질문 카드 등) | [README](partials/README.md) |

## 자세한 설명 (개발자용)

### 역할 요약

서버가 렌더링하는 화면. 계산·판단 없이 라우트가 넘긴 값을 표시만 한다.
Jinja2 자동 이스케이프가 켜져 있으므로 사용자 입력에 `|safe`를 쓰지 않는다.

### 기준

- 디자인: `프론트_예시/정책맵 워크스페이스.dc.html` 시안 (흰 카드, 파란 강조 #2563EB, Pretendard, 단계 표시줄, 근거 칩)
- checks.md 시안 차이 결정: 5단계, 규칙 표시는 최종기획 기준. [PDF로 저장]은 9/16에 추가(브라우저 인쇄 방식)

### `base.html`

- 상단 칩에 불러온 근거 파일의 종류·버전 표시 (`evidence.badge`), 오류면 `tag-error`
- 단계 표시줄: 원안을 보관하기 전에는 1단계만 열림
- 하단 고지: 합성/실제 표시 + "BC카드 공식 서비스가 아닙니다 · 공모전 제안용"
- 파비콘 파일을 두지 않고 빈 아이콘(`data:,`)을 지정해 브라우저의 `/favicon.ico` 자동 요청이 404로 남지 않게 한다 (6-4a)
- 모든 화면은 `templating.render()`로 그린다. 문맥에 `evidence`가 없으면 페이지 전체가 템플릿 오류가 난다

### 원칙

- 수치 표시는 패키지 루트 `formatting.py` 필터만 사용 (`{{ value | pct }}`). 템플릿 안에서 반올림·계산 금지
- None 값은 필터가 "자료 없음"/"계산 불가"로 바꾼다. `or 0` 같은 기본값 금지
- 색상: 방향 차이는 회색·파랑 중립색, 추가 확정 필요만 노랑(#A8761A). 빨간 경고 금지 (워크플로우 8-3)
- 모든 화면에서 "문제없음"과 "검토하지 않음"을 구분해 표시
- JS가 쓸 데이터는 `<script type="application/json">{{ data | tojson }}</script>`로 넘긴다

### `error.html`

근거 파일을 읽지 못했거나 막힌 설정 조합일 때 2~5단계에서 HTTP 503으로 표시. 오류 목록(수치 없음, 파일 이름만), "데이터 담당에게 전달, 고친 뒤 서버 재시작" 안내, [기획 입력으로] 버튼.
